# FormFlow

A production-quality Typeform-style form builder and respondent experience.

> **Status:** Design phase — awaiting approval before implementation.

## Overview

FormFlow lets creators build beautiful, interactive forms and collect responses through a polished one-question-at-a-time experience. Built as a take-home assignment demonstrating full-stack engineering quality.

## Stack

| Layer | Technology |
|---|---|
| Frontend | Next.js 15, TypeScript (strict), App Router |
| Backend | Python 3.14, FastAPI, Pydantic v2 |
| Database | SQLite with SQLAlchemy 2 + Alembic |
| Frontend Deploy | Vercel |
| Backend Deploy | Railway (persistent volume) |

## Repository Structure

frontend/    → Next.js application
backend/     → FastAPI application
docs/        → All documentation
